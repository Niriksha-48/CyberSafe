# 🔐 CyberSafe

CyberSafe is a web-based password strength checker that helps users understand whether a password meets common security requirements.

## 🚀 Features

- Password strength detection
- Live password requirements
- Minimum 8-character check
- Uppercase letter detection
- Lowercase letter detection
- Number detection
- Special character detection
- Password strength meter
- Show/Hide password option
- Responsive and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

CyberSafe/
│
├── index.html
├── style.css
├── script.js
└── README.md

## 🎯 Purpose

This project was created to demonstrate basic web development and cybersecurity awareness concepts, especially the importance of using strong passwords.

## ⚠️ Disclaimer

CyberSafe is an educational project. It does not store, transmit, or save user passwords.
